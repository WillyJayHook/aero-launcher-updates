# Как сделать Aero основным лаунчером

Установите [Aero TV 1.32](https://github.com/WillyJayHook/aero-launcher-updates/releases/download/v1.32/AeroTV-1.32.apk) поверх прежней версии и откройте приложение.

## Системный выбор

1. Откройте **Настройки Aero → Лаунчер по умолчанию → Системный выбор главного экрана**.
2. В окне Android выберите **Aero TV**. Если появится выбор «Всегда» / «Только сейчас», нажмите **Всегда**.
3. Нажмите **Home** на пульте и проверьте, что открывается Aero.

На некоторых телевизорах выбор доступен через **Настройки ТВ → Приложения → Приложения по умолчанию → Главный экран**. Названия пунктов зависят от прошивки.

## Перехват Home через специальные возможности

Этот способ подходит, если прошивка не позволяет сменить основной лаунчер или продолжает открывать штатный домашний экран. Для этого режима root и ADB не нужны.

1. Откройте **Настройки Aero → Лаунчер по умолчанию → Перехват кнопки Home**.
2. Нажмите **Включить**.
3. В системных настройках специальных возможностей найдите **Aero · кнопка Home**, включите службу и подтвердите разрешение Android.
4. Вернитесь в Aero. В настройках режима должен появиться статус **«Работает · Home открывает Aero»**.
5. Откройте другое приложение и нажмите **Home** — должен открыться Aero.

**На Xiaomi:** если открылись общие настройки ТВ, перейдите в **Настройки устройства → Специальные возможности → Aero · кнопка Home → Включить**.

Режим обрабатывает Home и появление штатного домашнего экрана; системное назначение лаунчера при этом не меняется. Служба не запрашивает чтение содержимого окон. Back, громкость и мультимедийные кнопки остаются доступны. Долгое нажатие Home также перехватывается. Если Home уже переназначена другой службой, проверьте её назначение.

Для отключения: **Настройки Aero → Лаунчер по умолчанию → Перехват кнопки Home → Выключить**. При возврате к штатному домашнему экрану выключите этот режим; разрешение службы при желании отключается отдельно в специальных возможностях Android.

Если раньше использовалась автонастройка Aero через ADB, в меню может отображаться **«Вернуть штатный лаунчер»**. Это отдельное восстановление прежней настройки; новый режим Home находится во втором пункте этого же меню.
