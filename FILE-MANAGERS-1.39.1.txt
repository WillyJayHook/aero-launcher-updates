Русский
Aero TV 1.39.1
Выбор обоев через сторонние файловые менеджеры. Aero показывает совместимые установленные приложения и позволяет выбрать нужное.
Настройки → Оформление → Обои → Файловый менеджер…
Если стандартного выбора файлов нет, используйте совместимый сторонний менеджер. Он должен поддерживать выбор изображений для других приложений; обычного просмотра файлов недостаточно. На Android 6–12 также доступен встроенный просмотр памяти ТВ/USB. Для старых файловых ссылок Aero при необходимости запрашивает разрешение на чтение. Отмена выбора сохраняет прежние обои.
Обновить можно через Настройки → Обновить Aero.

English
Aero TV 1.39.1
Choose wallpapers through third-party file managers. Aero lists compatible installed apps so you can select the one you want.
Settings → Appearance → Wallpaper → File manager…
If the system picker is missing, use a compatible third-party manager. It must support choosing images for other apps; browsing files alone is not enough. Android 6–12 also retains the built-in TV/USB browser. Aero requests read permission when needed for legacy file links. Cancelling keeps your previous wallpaper.
Update via Settings → Update Aero.

Español
Aero TV 1.39.1
Elige fondos con gestores de archivos de terceros. Aero muestra las aplicaciones compatibles instaladas para que elijas la que prefieras.
