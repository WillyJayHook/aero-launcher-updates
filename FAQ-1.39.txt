Aero TV 1.39 — исправления по отзывам
Обои: Настройки → Оформление → Обои → Выбрать своё изображение…. На Android 6–12 разреши чтение файлов и выбери JPG/PNG/WebP пультом. Aero сохраняет копию. Системный выбор остаётся доступен.
Полка: выбор приложения обнаруживает варианты Lampa по названию и пакету. Точный переход используется только при известном контракте; иначе выполняется объявленный приложением поиск или запуск с подсказкой искать вручную. Рабочий системный обработчик сохраняется.
Home: Настройки → Лаунчер по умолчанию → Не включается служба Home?
Android 13 и новее могут блокировать специальные возможности для APK, установленных из файла. Это ограничение Android, а не выключатель Aero.

Сначала попробуй включить «Aero · кнопка Home» в специальных возможностях. Если Android покажет «Ограниченная настройка», открой сведения о приложении Aero TV → ⋮ → «Разрешить ограниченные настройки». Затем вернись и включи службу. Названия зависят от прошивки.

Если на ТВ нет этого пункта, с подключённого компьютера можно выполнить команду ADB ниже, затем включить службу вручную. Команда сама службу не включает.

adb shell appops set tv.aero.home ACCESS_RESTRICTED_SETTINGS allow
