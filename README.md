## Установка и обновление

В каждом стабильном релизе два файла:

- `AeroTV-<версия>.apk` — подписанный APK;
- `update.json` — версия, ссылка на APK, размер и SHA-256 для встроенной проверки.

При первой установке скачайте APK и подтвердите установку в Android.
При обновлении устанавливайте поверх прежней версии: не удаляйте Aero TV
и не очищайте его данные, чтобы сохранить избранное, оформление, HDMI,
город погоды и подключение Полки.

Начиная с 1.22 лаунчер проверяет обновления при открытии. Ручная проверка:
«Обновить Aero» внизу основных настроек. Также доступно через
Настройки → Оформление → Дополнительно → Обновление лаунчера.
Нажмите «Обновить»; после загрузки подтвердите системную установку.
Если Android попросит разрешение установки из неизвестных источников,
разрешите его для Aero TV и вернитесь кнопкой Back.

Пакет: `tv.aero.home`.

`4f11169a535082caa047ccf03ce2a72ddf5c99f6a7215f844399f64d07bd66e4`.
